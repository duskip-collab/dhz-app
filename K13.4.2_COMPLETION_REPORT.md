## 3. Bezpečnostný model

1. **Subscription viazaná na používateľa:** klient neposiela `user_id`
   (spoof-proof) — pri návrhu RLS sa `user_id` dopočíta z relácie
   (`auth.uid()`); odber je prístupný len vlastníkovi.
2. **Oprávnenie odosielateľa:** Edge Function vyžaduje existujúce oprávnenie
   `communication.send` (RPC `has_permission`, jednotne s DB), inak 403.
   Žiadne nové roly/kľúče. Cron trigger: len so tajným `PUSH_CRON_SECRET`.
3. **Tajomstvá:** VAPID súkromný kľúč výhradne v env Edge Function;
   klient pozná len verejný `NEXT_PUBLIC_VAPID_PUBLIC_KEY`; logy nikdy
   nevypisujú hodnoty env (len konštatovanie chýbajúcej konfigurácie → 503).
4. **Client URL:** `parsePushPayload` v SW aj v hooke odhodí absolute URL
   (`https://`, `//`, `javascript:`) — open-redirect cez notifikáciu je
   vylúčený; fallback route je `/dashboard`.
5. **PWA integrácia:** `push`/`notificationclick` do `sw.js` pridané ako nové
   listenery, `FORBIDDEN_PATHS` aj cache stratégie (K13.4.1) nezmenené —
   push nikdy nič necacheuje.

## 5. Blokujúce závislosti (runtime odber→doručenie)

Popísané v poradí implementácie DBA/ops:

1. **Vygenerovať VAPID pár** (`web-push generate-vapid-keys`) → nastaviť
   `NEXT_PUBLIC_VAPID_PUBLIC_KEY` (aplikácia) a `VAPID_PRIVATE_KEY`,
   `VAPID_PUBLIC_KEY`, `VAPID_SUBJECT` (Edge Function secrets).
2. **Aplikovať migráciu `push_subscriptions`** (návrh nižšie) → hook samo
   prejde z `granted-local` na `granted-saved`; `send-push` prestane vracať 503.
3. **Nasadiť Edge Function** (`supabase functions deploy send-push`) +
   voliteľne `PUSH_CRON_SECRET` a pg_cron naplánovanie (STK/EK kontroly).
4. Manuálny end-to-end test na zariadení (povolenie → odber → odoslanie
   cez funkci → zobrazenie → klik → cieľová route).

## 6. Návrh schémy `push_subscriptions` (idempotentná migrácia — K APLIKÁCII DBA)

```sql
create table if not exists public.push_subscriptions (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id) on delete cascade,
  endpoint text not null unique,
  p256dh text not null,
  auth text not null,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
alter table public.push_subscriptions enable row level security;

drop policy if exists push_sub_self_select on public.push_subscriptions;
create policy push_sub_self_select on public.push_subscriptions
  for select to authenticated using (auth.uid() = user_id);

drop policy if exists push_sub_self_write on public.push_subscriptions
  for insert to authenticated with check (auth.uid() = user_id);
-- UPDATE+DELETE vlastných riadkov analogicky (auth.uid() = user_id).
```

**Prečo sa SQL neaplikovalo tu:** pravidlo fázy „žiadne breaking DB changes"
+ chýbajúce VAPID kľúče; hook a Edge Function sú navrhnuté tak, aby migráciu
detegovali za behu (fallback/degradácia namiesto pádu).

## 7. Otvorené riziká

- **Bez migrácie je odber lokálny** — hook informuje stavom
  `granted-local`; dokumentovať v UI (odporúča sa varovný text pri
  zapínaní notifikácií, kým nepríde migrácia).
- **`PushManager` na iOS** vyžaduje pridanú PWA na Home Screen — mimo
  kontroly tejto fázy (dokumentované správanie Safari).
- **Edge Function autentifikácia:** volajúci posiela svoje JWT v hlavičke
  (nie service key na kliente); CORS `*` zúžiť na produkčnú doménu pri
  nasadení.
- **`send-push` bez `VAPID_PUBLIC_KEY` env** — `setVapidDetails` potrebuje
  oba kľúče; doplnené do ENV zoznamu aj do kódu (čitanie
  `Deno.env.get("VAPID_PUBLIC_KEY")`).

## 8. Zhrnutie

Notifikačná infraštruktúra je pripravená: SW handluje `push`/`notificationclick`
s ochranou proti open-redirectu, hook `usePushNotifications` registruje odber
viazaný na prihláseného používateľa s idempotentným fallbackom pri chýbajúcej
tabuľke, Edge Function `send-push` overuje `communication.send` (alebo cron
secret) a odosiela Web Push s automatickým čistením zastaraných odberov.
Kontroly: unit 5/5, lint PASS, typecheck PASS (0 nových diagnostík), K13.3
30/30, K13.4.1 stratégie nedotknuté. Runtime doručenie je **BLOCKED** na
VAPID kľúčoch, migrácii (§6) a nasadení — presný postup v §5. Fáza je ukončená.
