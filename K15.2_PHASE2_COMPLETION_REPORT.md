## 🏗️ ARCHITECTURE

### Database Schema
```sql
member_courses (
  id uuid PRIMARY KEY,
  member_id uuid REFERENCES members,
  course_name text NOT NULL,
  certification_date date,
  expiry_date date,
  issuing_authority text,
  certificate_number text,
  notes text,
  created_at timestamptz DEFAULT now(),
  created_by uuid REFERENCES auth.users,
  updated_at timestamptz DEFAULT now(),
  updated_by uuid REFERENCES auth.users,
  UNIQUE(member_id, course_name, certification_date)
);
```

### Permission Model
- **READ:** All authenticated users (RLS SELECT policy)
- **CREATE:** MEMBERS_EDIT permission or higher role
- **UPDATE:** MEMBERS_EDIT permission or higher role
- **DELETE:** MEMBERS_EDIT permission or ADMIN role

### API Contract
```typescript
// POST /api/courses
Request: { member_id, course_name, ..., expiry_date }
Response: { success, data: MemberCourse } | { success: false, errors[] }

// PUT /api/courses/[id]
Request: { course_name?, certification_date?, ... }
Response: { success, data: MemberCourse } | error

// DELETE /api/courses/[id]
Response: { success, message }
```

### Client Components
- **CoursesTab:** Container for courses list + form modal
- **CourseFormModal:** Separate modal (not inline) for better UX
- Server component (member profile page) loads data once
- Client components handle user interaction + state
