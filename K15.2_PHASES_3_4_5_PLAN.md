## PHASE 3: MEMBER DRIVING LICENSES (~1.5 hours)

### Database Schema
**Table:** `member_driving_licenses`

```sql
CREATE TABLE member_driving_licenses (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  member_id UUID NOT NULL REFERENCES public.members(id) ON DELETE CASCADE,
  category VARCHAR(10) NOT NULL,          -- A, B, C, D, AM, etc.
  issue_date DATE NOT NULL,
  expiry_date DATE,                        -- NULL = no expiry
  country_code VARCHAR(2) NOT NULL,       -- CZ, SK, etc.
  license_number VARCHAR(50) NOT NULL UNIQUE,
  authority VARCHAR(255),                  -- Issuing authority
  notes TEXT,
  created_at TIMESTAMP DEFAULT now(),
  created_by UUID REFERENCES auth.users(id),
  updated_at TIMESTAMP DEFAULT now(),
  updated_by UUID REFERENCES auth.users(id)
);

-- Indexes
CREATE INDEX idx_member_driving_licenses_member_id ON member_driving_licenses(member_id);
CREATE INDEX idx_member_driving_licenses_expiry_date ON member_driving_licenses(expiry_date);
CREATE INDEX idx_member_driving_licenses_created_at ON member_driving_licenses(created_at);
CREATE UNIQUE INDEX idx_member_driving_licenses_license_number ON member_driving_licenses(license_number);

-- UNIQUE constraint: member can have max 1 license per category per country
ALTER TABLE member_driving_licenses ADD CONSTRAINT 
  uq_member_driving_license_per_category 
  UNIQUE(member_id, category, country_code);

-- RLS Policies (identical to member_courses)
-- SELECT: All authenticated
-- INSERT/UPDATE: MEMBERS_EDIT role or higher
-- DELETE: ADMIN role only
```

## PHASE 5: EXPIRY NOTIFICATIONS (~1.5 hours)

### Database Schema
**Table:** `expiry_notifications`

```sql
CREATE TABLE expiry_notifications (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  member_id UUID NOT NULL REFERENCES public.members(id) ON DELETE CASCADE,
  notification_type VARCHAR(50) NOT NULL,  -- course_expiring, license_expiring, document_expiring
  reference_id UUID,                       -- course_id, license_id, or document_id

  expiry_date DATE NOT NULL,
  days_until_expiry INTEGER,               -- Calculated at creation
  notification_sent_at TIMESTAMP,
  viewed_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT now()
);

-- Indexes
CREATE INDEX idx_expiry_notifications_user_id ON expiry_notifications(user_id);
CREATE INDEX idx_expiry_notifications_member_id ON expiry_notifications(member_id);
CREATE INDEX idx_expiry_notifications_notification_sent_at ON expiry_notifications(notification_sent_at);
CREATE INDEX idx_expiry_notifications_viewed_at ON expiry_notifications(viewed_at);
```

## RISK MITIGATION

| Risk | Mitigation |
|------|-----------|
| File upload limits exceeded | Max 50MB, validate on client + server |
| Storage bucket access denied | Use service_role with proper RLS |
| Concurrent file uploads | Use transaction to link file_path with DB record |
| Notification spam | Only create 1 notification per item per month |
| Missing date fields | Allow NULL expiry_date (some docs/licenses don't expire) |
| Circular RLS policies | Avoid recursive member_id checks; use direct role checks |
| Performance: Too many files | Paginate document list, lazy-load previews |
