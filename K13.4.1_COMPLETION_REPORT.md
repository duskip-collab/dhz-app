## 3. SW stratégie (public/sw.js v2)

| Typ požiadavky | Stratégia | Cache |
|---|---|---|
| `/_next/static/*` (hashované, nemenné) | **Cache-First** | `dhz-static-v2` |
| `/icons/*`, `manifest.webmanifest`, `favicon.ico` | **Stale-While-Revalidate** (okamžitá odpoveď + tichá obnova) | `dhz-static-v2` |
| Navigácie na prevádzkové zoznamy: `/members`, `/training`, `/competitions`, `/calendar`, `/inventory`, `/inventories`, `/vehicles`, `/vehicle-equipment`, `/gear` | **Network-First** (čerstvosť má prednosť; offline → posledná uložená HTML verzia, inak 503) | `dhz-pages-v2` |
| Auth (`/auth`, `/login`, …), `/api/`, `/rest/v1/`, `/graphql/`, `/functions/`, `/supabase/` | **Network-Only** (nikdy cache) | — |
| `**/finance*`, `**/reports*`, `/dashboard`, `/documents`, `/profile`, `/settings`, `/admin` | **Network-Only** (finančné údaje a citlivé prehľady NIKDY v trvalej cache) | — |
| Cross-origin (Supabase REST/auth, iné originy) | **Network-Only** | — |
| Ostatné (RSC prefetches, ostatné HTML) | **Network-Only** | — |

Ukladajú sa len čisté odpovede (`ok && 200 && !redirected`). `activate`
maže staré `dhz-*` cache (vrátane v1); `install` preskakuje chýbajúce súbory.

## 4. Bezpečnostný model offline cache

1. **Žiadne finančné údaje v trvalej cache:** `/finance`, `/reports`
   (finančné reporty), `/dashboard` (súhrny) a `/documents` sú vo
   `FORBIDDEN_PATHS` → network-only; `PAGES_PATTERNS` ich neobsahuje.
2. **Auth/RLS nedotknuté:** `FORBIDDEN_PATHS` + cross-origin vetva zabraňujú
   cacheovaniu `/auth`, `/rest/v1/`, `/functions/` a akéhokoľvek Supabase
   endpointu — tokeny a API odpovede neopúšťajú sieť.
3. **RLS dáta mažú pri odhlásení:** `dhz-pages-v2` obsahuje HTML stránok
   chránených RLS (uložené len pre prihláseného používateľa). Oba logout
   handlery (`AppShell`, `UserMenu`) po `signOut()` volajú
   `clearOfflinePagesCache()` — na zdieľanom zariadení nezostávajú dáta
   ďalšieho používateľa.
4. **Neinvazívne:** cache neobchádza autorizáciu — offline odpoveď je
   archív poslednej oprávnenej HTML verzie; žiadne nové dáta ani write
   operácie sa offline nevykonávajú.

## 7. Otvorené riziká a závislosti

- **HTML caching vs. RSC:** Next.js RSC prefetches zostávajú network-only
  (branch 7 v SW) — offline navigácia funguje cez celostránkovú odpoveď
  z `dhz-pages-v2`; prefetch offline sa nepoužije (akceptované obmedzenie).
- **Veľkosť cache:** každá uložená stránka je HTML ~desiatky KB; strop cache
  nie je limitovaný (počet stránok je malý — 9 patternov). Pri rozmachu
  zvážiť LRU (mimo rozsahu).
- **Verzia cache:** pri budúcich zmenách SW bump `STATIC_CACHE_NAME`/
  `PAGES_CACHE_NAME` (activate automaticky maže staré `dhz-*`).
- **Test na zariadení:** odporúčané manuálne overenie na reálnom zariadení
  (Android Chrome / iOS Safari) — service worker sa v dev režime správa
  odlišne (niektoré prehliadače ho v incognito neregistrujú).

## 8. Zhrnutie
