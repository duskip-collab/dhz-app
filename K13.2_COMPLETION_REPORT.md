## 4. Bezpecnostne zistenia

- Stranky vyzaduju `finance.view` cez `requirePermission` (server).
- Zapis: `finance_transactions` RLS `finance.create` / `finance.edit`;
  RPC `finance_create_transfer` interne kontroluje `finance.create`
  (+`finance.edit` pri `p_post=true`).
- POSTED checkbox je len UI priznak; skutocnu autorizaciu vynucuje DB
  (RLS + guard triggre + RPC permission check), nie klient.
- Server client pouziva anon key + cookies (`@/lib/supabase/server`);
  service-role key sa v prehliadaci nepouziva.
- Peniaze: DB `bigint` minor units; UI prevod EUR↔centy
  (`Math.round(EUR*100)` pri zapise, `/100` + 2 desatinne pri zobrazeni).
