## PHASE 3: MEMBER DRIVING LICENSES ✅

### Database Schema
**Migration:** `20261103_member_driving_licenses.sql` (8.3 KB)

Table structure:
```sql
member_driving_licenses (
  id UUID PRIMARY KEY,
  member_id UUID FK → members,
  category VARCHAR(10),        -- A, B, C, D, AM, A1, A2, B1, C1, D1
  issue_date DATE NOT NULL,
  expiry_date DATE (nullable),
  country_code VARCHAR(2),     -- ISO 3166-1 (CZ, SK, etc.)
  license_number VARCHAR(50) UNIQUE,
  authority VARCHAR(255),      -- Issuing authority
  notes TEXT,
  created_at TIMESTAMP,
  created_by UUID FK → auth.users,
  updated_at TIMESTAMP,
  updated_by UUID FK → auth.users,
  
  UNIQUE(member_id, category, country_code) -- Max 1 per category/country
)
```

Features:
- Indexes: member_id, expiry_date DESC, created_at DESC, license_number
- RLS policies:
  - SELECT: All authenticated users
  - INSERT/UPDATE: MEMBERS_EDIT role (trainer/admin)
  - DELETE: MEMBERS_EDIT role
- Triggers: Auto-update updated_at, updated_by, created_by
- Idempotent: IF NOT EXISTS guards for safe re-migration
