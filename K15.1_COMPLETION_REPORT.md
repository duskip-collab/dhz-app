## 📊 Implementation Details

### Database Schema Used
- ✅ `members` table
- ✅ `member_guardians` table
- ✅ `equipment_assignments` table (with foreign key to equipment_items)
- ✅ `training_attendance` table (with foreign key to trainings)
- ✅ `competition_lineups` table (with foreign key to competition_teams)

### Query Performance
- Parallel fetching of all sections (Promise.all)
- Limit results: 50 most recent for training and competitions
- Proper indexing through foreign keys
- RLS policies enforced through service layer

### Permission Model
- ✅ MEMBERS_VIEW required for profile access
- ✅ Server-side permission check
- ✅ Graceful 403 error if unauthorized

## 🎓 Lessons Learned

1. **Object.entries type inference** — TypeScript requires explicit casting when reducing to Record<string, any[]>
2. **Icon component types** — Lucide icons are React components, not just ReactNode
3. **JSX in map callbacks** — Parentheses and arrow function syntax must be exact
4. **UTF-8 encoding in git** — Quote characters can be corrupted; full file rebuild preferred
